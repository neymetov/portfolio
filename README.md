# Личный сайт Эльшана Нейматова

Astro (статическая сборка) + React-острова + Keystatic. ТЗ — `Elshan_Neymatov_dev_brief_ClaudeCode.md`.

## Запуск

```sh
npm install
npm run dev      # сайт на :4321, админка на :4321/keystatic
npm run build
```

## Стили и токены

`design-tokens.tokens.json` — выгрузка Figma Variables, единственный источник значений.
`npm run tokens` пересобирает из него `src/styles/tokens.css` (запускается автоматически
перед `dev` и `build`). Руками `tokens.css` не правим.

Известное ограничение: выгрузка содержит только один режим переменных (mobile).
Desktop-значения Spacing/Radius (margin 80, l 24, xl 48, radius xxl 20) сняты из фреймов
Figma и лежат отдельным блоком в начале `src/styles/global.css`. После переэкспорта
токенов с обоими режимами этот блок должен уехать в генератор.

Типографика: в токенах два набора размеров (переменные и текстовые стили). Генератор
трактует их как мобильный и десктопный концы шкалы и связывает через `clamp()`.

## Контент

Keystatic пишет JSON в `src/content/`, Astro читает те же файлы через content collections
(`src/content.config.ts`). Схема — `keystatic.config.ts`.

- синглтоны: `site` (SEO), `home`, `worksPage`, `navigation`, `siteFooter`;
- коллекции: `works`, `skills`, `categories`, `processes`.

Админка живёт только в dev: `npm run dev` выставляет `KEYSTATIC=1`, и интеграция
подключается вместе с серверным API. В прод-сборку она не попадает — с локальным
хранилищем Keystatic пишет файлы прямо в репозиторий, поэтому на хостинге бесполезна.
Чтобы редактировать контент на домене, нужно переключить `storage` на `github`
и вернуть серверный адаптер.

Названия синглтона и коллекции не должны совпадать: `ui.navigation` ссылается на них
по ключу, и при одинаковых именах раздел в админке становится неоднозначным.

Количество карточек в ряду на `/works` и состав `galleryBlocks` на `/work/[slug]` задаёт
редактор — вёрстка работает при любом N.

Изображения работ и иконки skill-карточек сейчас — SVG-заглушки из
`scripts/make-placeholders.mjs`; заменяются через админку. Логотипы вузов/компаний
и hero-картинка взяты из Figma.

## Деплой

Cloudflare Pages с автосборкой из репозитория. Настройки проекта в панели Pages:

- Build command: `npm run build`
- Build output directory: `dist`
- Node version: 22 или новее (нужен для Astro)

Серверный адаптер не нужен: сборка отдаёт чистую статику. Те же параметры продублированы
в `wrangler.jsonc` — с ним работает и разовый деплой из консоли (`npx wrangler pages deploy`,
после `npx wrangler login`).

Домен подключается в настройках проекта Pages после регистрации.
